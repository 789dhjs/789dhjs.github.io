java项目部署上线流程

服务器

选择带有宝塔版本的centos7以上的服务器

根据服务器给的宝塔网址登录宝塔，设置管理员用户名和密码并绑定宝塔官网账号（提前注册宝塔账号）

绑定成功后直接点击推荐LNMP的下载

等待安装

添加Mysql数据库，记得访问权限是所有人，如果项目中有redis还要添加redis（记得保存用户名和密码）

然后放开3306端口

如果显示本地服务器异常要点击root密码重置一下就行

然后用idea的数据库连接功能试着连接一下，查看是否正常

主机填写服务器ip地址，用户和密码都是跟上一张图一样的

接着我们进入这个远程的数据库中，将我们自己的表的数据复制下来

复制完成后就可以去安装java环境了

依次点击右边的网站，添加java项目，项目JDK，添加JDK信息

我的项目是java11，所以我直接安装jdk11了，等待安装即可

环境配置完成后我们要去修改我们自己项目的yml文件，尤其注意，要将数据库等远程连接的链接地址将localhost修改为服务器ip地址不要带http://，username和password也要修改为之前修改的值

接着启动一下项目查看是否正常，若启动正常就可以开始打包项目了

由于我的项目是存在多个模块的，所以打包的时候要注意一下

在除开入口模块（application所在类）的每个子模块中添加Maven打包程序

在入口模块的xml文件增加这一段，让其可以运行

直接在父模块点击package即可，打包完成后，把包含application的入口jar包拿到，就可以直接上传文件到宝塔上了

后端

点击新建java文件，把上传到宝塔上面的java文件放入项目中直接保存配置运行即可

开放9988端口(自己项目是什么端口就放开什么端口)

前端

打开我们的前端源代码

修改request.ts文件中的baseurl的localhost为自己的ip地址

修改package.json中的scripts，加入

为什么本来就有build还要加入一个pure-build呢是因为脚手架内置的会执行类型检查，只要有一点不规范的地方就会导致打包失败，但是这样太影响效率了，干脆自己引入一个更加纯粹的干净的打包命令，直接执行引入的命令

构建完成后会生成一个dist文件夹

把这个dist文件夹通过宝塔上传到服务器上

然后创建PHP项目点击添加站点，输入域名即可

创建成功后点击设置点击后边的配置文件修改配置文件,将后端端口作为转发端口，实现nginx转发
